# Mini Video Tool — Local Web

واجهة ويب محلية تعمل من المتصفح، بينما `Bun` يشغّل `yt-dlp` و`FFmpeg` على موارد نفس الجهاز.

## تشغيل

من جذر المشروع:

```powershell
bun local-web/server.ts
```

أو افتح `start-web.cmd`.

يفتح التطبيق على:

`http://127.0.0.1:4173`

## التدفق

1. الصق رابط يوتيوب.
2. اقرأ بيانات الفيديو بدون تنزيله.
3. حدد البداية والنهاية والجودة.
4. اضغط **تحميل الجزء وتحليل الصمت**؛ يتم تنزيل الجزء المحدد فقط ثم تحليل الصمت محليًا.
5. استخدم التايم لاين للـseek ومراجعة الصمت والكابشن واللوجو.
6. أضف لوجو واسحبه فوق الفيديو، واضبط الحجم والشفافية والمدة.
7. حمّل كابشن يوتيوب العربي أو استورد ملف SRT، واضبط الحجم والمكان.
8. صدّر؛ القص + اللوجو + الكابشن يطبقوا في التصدير النهائي، والملف يذهب إلى `Downloads\MiniVideoTool`.

الخادم مربوط بـ `127.0.0.1` فقط ولا يرفع الفيديو إلى خادم خارجي.
