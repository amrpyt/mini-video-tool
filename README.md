# Mini Video Tool

أداة ويندوز خفيفة لثلاث حاجات:

1. **تحميل جزء فقط من يوتيوب** باستخدام `yt-dlp --download-sections` بدل تنزيل الفيديو كاملًا.
2. **قص الصمت** من فيديو محلي.
3. **إضافات بسيطة للفيديو**: صور وPNG شفاف وشريط أسود وكابشن اختياري.

أثناء الشغل، لوحة العمليات تعرض بيانات حقيقية لحظيًا: المرحلة والنسبة، بيانات الوسائط المنقولة وسرعتها، الزمن والمتبقي، المقطع المطلوب، حجم الملف والمساحة الحرة، ومؤشرات FFmpeg مثل سرعة المعالجة ومعدل الإطارات ومعدل البت. السجل التقني الكامل متاح بزر منفصل.

## أسرع تشغيل على ويندوز

1. نزّل `MiniVideoTool-portable.zip` من [آخر إصدار](../../releases/latest) وفك الضغط.
2. الحزمة المحمولة فيها `MiniVideoTool.exe` ومعاه مجلد `bin` جاهز (`yt-dlp` + `ffmpeg` + `ffprobe`).

ولو بتشغّل السورس بدل الحزمة، تقدر تثبت الأدوات مرة واحدة:

```powershell
winget install --id yt-dlp.yt-dlp --exact
winget install --id Gyan.FFmpeg --exact
```

3. افتح `MiniVideoTool.exe`.

جودات يوتيوب: Best / 1080p / 720p / 480p / 360p.

## ملاحظات مهمة

- **Best** = أعلى جودة متاحة من يوتيوب بعد معالجته، وليست الملف الخام الأصلي قبل الرفع.
- التحميل الجزئي لا يجبر الناتج على MP4.
- بداية ونهاية الجزء قد تختلف قليلًا حسب الـkeyframes لأننا لا نعيد ترميز الجزء أثناء التنزيل؛ هذا أسرع ويوفر النت ويحافظ على الجودة.
- للجودات المحددة 1080/720/480/360 يفضّل البرنامج مسار YouTube HLS السريع عند توفره، ويرجع تلقائيًا للمسار العادي عند الحاجة.
- إخراج الفيديو المعدّل يستخدم MP4/H.264 ويستفيد تلقائيًا من Intel Quick Sync عند توفره، مع fallback للمعالج إذا فشل التسريع العتادي.
- صور/PNG الثابتة تُجهّز بالحجم النهائي مرة واحدة قبل الرندر بدل إعادة تصغيرها في كل فريم.
- كابشن يوتيوب العربي اختياري. يمكن تعديل الخط والحجم والألوان والحد والشادو والخلفية وشفافيتها والموضع والمحاذاة والهامش وBold/Italic.
- البرنامج يبحث محليًا عن `Ping AR LT Regular`. ملف الخط نفسه **غير موجود في الريبو**.

## تشغيل السورس

يتطلب Python 3.13 وPillow. بعد تثبيت أدوات الفيديو بالطريقة فوق:

```powershell
pip install -r requirements.txt
python app.py
```

## بناء EXE

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name MiniVideoTool app.py
```
